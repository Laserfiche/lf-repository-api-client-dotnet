Detailed Description

Request body for partial-update of an entry's records management properties. Every member is
optional: null = leave unchanged. Id members accept 0 to clear the assignment.
Dates are set by supplying a value; the two clearable dates (record folder triggerDate
and record lastReviewDate) are cleared via their explicit clear* flags.
Applying this update to a plain document promotes it to a record, and to a plain folder
promotes it to a record folder, before the properties are applied. Members that do not apply
to the entry's resulting type (for example record-folder members on a document record) are
rejected with 400.
