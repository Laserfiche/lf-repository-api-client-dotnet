Detailed Description

The records management properties of a record or record folder. This is the abstract base; the concrete shape is
RecordProperties for a document record (RecordType = Record)
or RecordFolderProperties for a record folder (RecordFolder). Members
common to both record and record folder live here; type-specific members live on the subtypes.
Many members are computed by the repository and are read-only — they are noted as such and are
ignored on update.
