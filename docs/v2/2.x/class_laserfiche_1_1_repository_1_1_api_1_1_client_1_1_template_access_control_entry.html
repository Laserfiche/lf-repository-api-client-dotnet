Detailed Description

A single access control entry (ACE) on a template definition: one trustee, whether its
rights are allowed or denied, and the rights themselves. A trustee that has both allowed
and denied rights is represented as two ACEs. Unlike entry ACEs, template ACEs have no scope
and are never inherited.
